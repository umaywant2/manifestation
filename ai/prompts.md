# **Project Manifestation — AI Prompt Patterns**

This document defines the **canonical prompt structures** used by structural AIs working within Project Manifestation.  
These prompts ensure coherence, safety, reproducibility, and alignment with RTT engines.

All prompts must follow the Manifestation session context.

---

# **1. Operator‑Level Prompts (RTT/1)**

### **1.1 Define an Operator**
```
Define the operator <OPERATOR_NAME>.

Include:
- operator family (E, S, A, M, R, X, Ω)
- purpose
- constraints
- failure modes
- RTT/1 grammar alignment
- RTT/2 stacking behavior
- RTT/3 detection rules
```

### **1.2 Analyze Operator Behavior**
```
Analyze the behavior of <OPERATOR_NAME> under the following conditions:
<CONDITIONS>

Include:
- expected behavior
- drift risks
- resonance interactions (if any)
- safety boundaries (X-operators)
```

### **1.3 Compare Two Operators**
```
Compare <OPERATOR_A> and <OPERATOR_B>.

Include:
- functional differences
- stacking differences
- failure mode differences
- resonance implications
- safety considerations
```

```

- updated safety requirements
```
