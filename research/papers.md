# **Project Manifestation — Papers & Publications**

This document serves as the **central index** for all papers, reports, models, and long‑arc research outputs produced within Project Manifestation.

All papers listed here must follow:

- the Manifestation session context  
- RTT/1 operator grammar  
- RTT/2 stacking rules  
- RTT/3 structural detection  
- open‑access licensing  

This index will expand as the project grows.

# **6. How to Contribute a Paper**

Students and researchers may submit papers by:

- creating a new file under `/research/papers/`  
- following the Manifestation session context  
- using RTT operator grammar  
- including structural diagrams when relevant  
- linking the paper to open questions  
- adding the paper to this index  

All papers must be open‑access and reproducible.
